# spriteself

A proposal for a local asset organizer for indie game developers, with source and license tracking.

The repository contains documentation and community contribution files. It does not yet include a working asset database, import pipeline, or desktop application.

## Contribute to the proposal

Start with [CONTRIBUTING.md](CONTRIBUTING.md). The next useful contribution is a small implemented slice with documented inputs, outputs, and setup, rather than claims about features that do not exist yet.
