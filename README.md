# spriteself

A simple local asset organizer for indie game developers to find sprites, textures, models, and audio, and track their sources and licenses.

---

## Purpose

spriteself aims to help indie developers manage their game assets by providing tools or workflows tailored to their needs. It focuses on enabling solo developers and small teams to organize their collections efficiently and keep track of asset sources and licenses.

## Audience

This project is designed primarily for solo indie game developers and small teams who manage their own asset collections. The initial focus is on hobbyists and game jam participants who need a simple, local solution to organize sprites, textures, models, audio, and related metadata.

## Current Status

This repository currently contains the foundational documentation and scaffolding. Implementation and usage instructions will follow as the project develops.
